# 仓库同步

远程仓库：<https://github.com/AdminQAq678/tk-mg-sys.git>  
默认分支：`main`

在仓库根目录 `tk-mg-sys` 执行下列命令。Windows PowerShell 可直接复制。

## 首次克隆

```powershell
git clone https://github.com/AdminQAq678/tk-mg-sys.git
cd tk-mg-sys
```

已有本地目录、只缺远程时：

```powershell
cd tk-mg-sys
git remote add origin https://github.com/AdminQAq678/tk-mg-sys.git
git fetch origin
git branch -u origin/main main
```

## 拉取远程最新

先保存或提交本地改动，再拉：

```powershell
cd tk-mg-sys
git checkout main
git pull origin main
```

有未提交改动又不想先提交时，可暂存后再拉：

```powershell
git stash -u
git pull origin main
git stash pop
```

## 提交并推送本地最新

```powershell
cd tk-mg-sys
git checkout main
git pull origin main
git add -A
git status
git commit -m "说明这次改动的原因"
git push origin main
```

不要把 `infra/.env`、`.env`、密码和构建产物提交进仓库。

## 两边都有提交（先同步再推）

```powershell
git checkout main
git pull origin main
# 若有冲突：改文件 → git add 冲突文件 → git commit
git push origin main
```

## 用本地直接覆盖远程

仅在确认远程 `main` 可以丢掉、且要以本机代码为准时使用。会改写远程历史，其他人需要重新拉分支。

```powershell
cd tk-mg-sys
git checkout main
git add -A
git commit -m "说明这次改动的原因"
git push --force-with-lease origin main
```

别人已经基于旧 `main` 开发时，不要用覆盖推送。
