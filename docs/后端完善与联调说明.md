## 人工核对与回退

参考 Agent 的 heartbeat `cancel` 不能被视为“设备执行已停止”的保证。
超时、断连、服务重启和缺失终态都可能导致结果未知；协议没有
attempt fencing 或 guard response 的确认编号，不能承诺物理操作恰好执行一次。
未知任务不可自动重放；迟到回报不能解锁未知租约。

独立确认盒子执行已停止后才可通过以下工具核对终结：

```sh
# 注入 BOX_TASK_ID、BOX_RECONCILIATION_RESULT（failed/cancelled）、
# BOX_EXECUTION_STOP_CONFIRMED=true、BOX_RECONCILIATION_EVIDENCE 和系统 actor。
bun apps/api/src/reconcile-box-task.ts
```

核对证据写入审计，不允许把未知执行直接标记 succeeded。
确认终结后下一轮同步才迁移归属，不自动继续旧任务。

回退前停止同步、暂停新下发并核对所有执行；保留新增 schema 和历史归属记录。
不能在已经迁移设备归属后直接恢复旧复合外键、删除映射表或运行破坏性 down
迁移。旧版 Agent 后端缺少未知结果隔离，不应在有待核对任务的库上直接恢复服务。
必要时通过经验证的完整备份恢复到独立库，人工核对设备现实状态后再切换，
禁止将数据库恢复等同于设备执行回滚。

### 检测安全与运行配置

- Docker API 镜像使用固定版本及 digest 的 sing-box `1.12.12`。
  非容器启动须安装同版本核心，通过 `PROXY_PROBE_BINARY` 指定可执行文件；
  默认 `/usr/local/bin/sing-box`。API 服务账号只需执行权限，无需 TUN、root 或
  网络管理能力；缺少核心会报检测失败，不会改用直连或模拟结果。
- 固定服务为 `https://api.ipapi.is/` 和 `https://api.ip.sb/geoip`。
  校验 HTTPS 证书，禁止重定向，响应上限 64 KiB，处理结构化和匿名扁平 IPAPI
  响应。公开接口可限流或变更，供应商 429 会保存限流失败；无付费 SLA 保证。
  返回 429 后停止继续尝试加速候选，不通过自动切换服务或直连绕过限流。
  投产前还须核实供应商的配额、商用许可和可用性，本轮未配置付费服务授权。
  查询服务会看到代理出口 IP，这是该功能正常工作的必要条件。
- 代理服务器仅允许公网 IP/域名；拒绝私网、保留、loopback、链路本地、
  metadata 和混合公私 DNS 结果。每个节点解析后固定 IP，TLS SNI 保留原域名。
  实验测试的 loopback resolver 只通过测试工厂传入，生产没有环境变量绕过。
- 只接收单个白名单 V2 出站，禁止任意路由、入站、detour 和关闭 TLS 校验。
  临时认证入口仅监听 loopback，随机凭据；目录 0700、配置文件 0600，
  核心日志关闭，finally 杀子进程并清理文件，API 关闭时清理剩余子进程。
- 同组事务 advisory lock 校验加速节点归属、资格、重复、自引用、循环及最多
  8 层链路；正在被引用的节点不能删除、停用或取消加速资格。账号或活跃任务
  使用的代理不能删除。跨管理员的节点不能组成链路。
- 单次总预算约 25 秒，候选最多 10 条，每个候选最多 10 秒。
  每组最多 4 个并行检测，全进程最多 4 个核心；同代理检测独占、10 秒冷却、
  60 秒失效租约可重新领取。修改目标或上游配置会清除旧结果；检测完成时
  核对全部节点 revision，过时结果不入库，不能覆盖新配置的状态。

## 2026-10-07 IP 信息查询语义修正（现行行为）

用户明确要求只查询配置 IP，不验证能否连接代理节点。本轮覆盖之前 `/detect`
的连通性解释，已写入 `AGENTS.md`。参考站点只读查看，没有请求其检测、修改其
数据或复制其账号凭据；截图中的说明不作为代理可用性保证。

- `/detect` 路径、权限检查及 `channel/mode/useTurbo` 请求字段保持兼容。
  `useTurbo` 仅兼容旧请求，当前忽略；新响应固定 `use_turbo:false`、
  `accelerator_id:null`，不连接任何代理或加速节点，不解密代理凭据。
- 查询的是 `configuration.host` 的公网 IP。域名先检查全部 DNS 答案，只允许
  公网答案并选择一个作为本次 `target_ip`；混合内外网和保留地址仍拒绝。
  IP.SB 请求 `/geoip/{ip}`，IPAPI 请求 `?q={ip}`，不使用省略 IP 后返回的服务端
  出口信息。查询结果 IP 必须与请求 IP 一致，IPv6 按规范化地址比较。
- `check_result` 新增 `detection_type:"ip_lookup"`、`target_ip`、
  `connectivity_checked:false`。信息写入原 JSON 字段，**不需要新增 SQL 迁移**。
  旧结果及历史记录保留，页面详情将无新类型标记的旧结果标为历史检测，重新

### 迁移与兼容性

- `0037` 新增 `business_label.scope`，唯一约束为
  `(administrator_id, scope, kind, name)`；不同域、不同管理员或不同类型可同名。
  原盒子接口路径与请求体不变，兼容视图只查询 `device` 域。
- 旧分类按设备引用和现有业务 `tags` 推断来源，设备引用优先保留原 ID。
  同名多域分类复制必要目录记录，不改写业务数组、记录备注或设备关联。
  没有证据的闲置旧分类保留原 ID 于 `legacy`，不猜测来源，也不删除。
- 四类业务写入触发器按域幂等登记；账号 `tags[1]` 是主分组，
  `tags[2:]` 是附加标签。触发器与目录删除使用包含 scope 的同一事务锁。

- 设备触发器拒绝错域、错类型和其他管理员分类。同步暂停归属时，允许
  分类留在原权限组并等待核对；确认移交后按原同步规则清除设备分类，

- `GET/POST /api/labels/catalog?page=<路径>&scope=<域>`；
  `DELETE /api/labels/catalog/:id?page=<路径>&scope=<域>`。
  省略 scope 时使用页面默认域，POST 仍为 `{kind,name}`。
  GET 目录及分类记录新增 `scope`；新前端校验响应域，拒绝混合或错域目录。
