# 个人资料实名认证验收

## 已实现行为

- 头像菜单“个人资料”进入 `/profile`，展示名字、邮箱、角色和实名认证。
- 移除个人实名认证侧栏菜单；平台实名认证管理与解绑功能保留。
- 未认证、失败或解绑后的适用管理员可以在资料页上传身份证并单独同意核验。
- 认证后只显示“已认证”，隐藏上传、证件详情和原“进入系统”按钮，停留在个人资料页。
- 提交成功与轮询确认成功都会刷新当前会话，恢复业务访问。
- 强制认证统一跳转 `/profile`；旧 `/identity-verification` 链接兼容跳转。
- 豁免账号显示“无需认证”，功能关闭时显示“暂未开放”。认证范围与后端接口没有改变。
